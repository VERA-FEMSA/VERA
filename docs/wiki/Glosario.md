# Glosario

| Término | Significado en VERA |
| --- | --- |
| **Propuesta** | Iniciativa registrada para revisión antes de convertirse en auditoría en ejecución. |
| **Auditoría activa** | Auditoría aprobada que ya inició y aún no se cierra. |
| **Riesgo** | Registro evaluado por probabilidad e impacto, con historial de reevaluaciones. |
| **Control** | Medida vinculada a uno o más riesgos, con evaluaciones de efectividad. |
| **Hallazgo** | Registro de una situación identificada, vinculado a riesgo y control cuando corresponde. |
| **Evidencia** | Referencia o archivo privado vinculado a una entidad autorizada. |
| **Pendiente** | Actividad derivada del estado actual; marcarla como leída no completa la acción. |
| **Bitácora** | Eventos de acceso y cambios relevantes; no equivale a una captura de pantalla. |
| **RBAC** | Autorización por rol, complementada por acceso al expediente concreto. |
| **Modo `memory`** | Datos locales temporales del backend; se pierden al reiniciar. |
| **Modo `supabase`** | Repositorios conectados a datos persistentes, sujetos a migraciones y configuración. |
| **Check de CI** | Resultado de una verificación automatizada para un commit y entorno determinados. |
| **Aceptación** | Confirmación de que todos los criterios de una HU se cumplieron con la evidencia requerida. |
| **Cita de IA** | Referencia a un registro que el servidor permitió consultar; no certifica por sí sola la exactitud de toda una respuesta generada. |

Para un término funcional no definido aquí, consulta el [plan de pruebas](https://github.com/humbertofigb15/VERA/blob/main/docs/testing/test-plan.md) o el [código vigente](https://github.com/humbertofigb15/VERA).
